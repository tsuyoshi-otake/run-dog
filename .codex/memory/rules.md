# Verified project rules

- Usage catch-up retries must have an explicit terminal outcome. A permanently unreadable path must not own global finalization or starve hot-file discovery; verify this contract with a component regression, stateful PBT, and TLC liveness properties.
- A restored usage checkpoint can contain thousands of old file registrations. Prioritize current-day discovery, registration, and provider-balanced reads, and reserve read capacity after registration. Verify against a restored backlog and the production usage state so Today does not remain at zero while month totals advance.
- Run Cargo tests and Clippy sequentially against one toolchain in the shared target directory. A mixed-toolchain target produced `E0514` during parallel verification; `cargo clean` followed by sequential tests and Clippy passed.
- When TKW runs a concrete Cargo image, also set `RUSTUP_TOOLCHAIN=1.97.1-x86_64-pc-windows-msvc`; `rustup which cargo --toolchain ...` alone did not pin the `rustc` selected by Cargo and reproduced `E0514` after dependencies were built by 1.97.1 but the crate was compiled by 1.96.0.
- Do not use directory mtime equality to skip discovery at provider hot roots. Filesystem timestamp resolution can leave the parent mtime apparently unchanged after a new session directory is created; always enumerate the Claude projects root and the current Codex month, while retaining caches below those boundaries.
- Win32 resource ownership transfers only on successful API calls: delete a newly created region if `SetWindowRgn` fails, and explicitly destroy a submenu if attachment fails. Invalid-handle probes reproduced retained GDI regions and an orphan menu; success-path RAII alone does not cover these failures.
- Usage cursor retirement must cover both `UsageCollector.files` and persisted cursors. Persist the last active month, preserve current-month offsets even for missing files, and rebuild Codex cumulative baselines when retired sessions resume. Regressions cover a bounded sweep, durable restart mid-sweep, legacy checkpoints, and resumed sessions without double counting.
- Retire missing paths using their recorded provider, not `canonicalize`: canonicalization fails once a path disappears. Filter queued paths once at the end of a retirement pass to avoid quadratic queue scans; a newly modified retired file may re-register during the pass.
- GDI may cache a deleted region handle, so `GetObjectType` is not a reliable deletion oracle. Verify region failure cleanup using a warmed-up resource count in an isolated test process; concurrent GUI tests must not share that measurement.
- Before committing a release, check repository-local Git identity as well as existing history. Existing commits used the project noreply identity while inherited Git configuration still named a personal account; set the local identity to the public project identity before making new commits.
- Same-size rewrite tests that keep the file ID and first 64 bytes unchanged must explicitly move mtime: the collector's documented hint uses millisecond timestamps, and two fast CI writes can share one millisecond. Set `FileTimes` and assert `SameSizeRewriteHint`; sleeping or rerunning a flaky test is not a fix.
- Claude catch-up across read-budget ticks must retain partial-to-final revision candidates until the file's unread bytes are consumed, even when its mtime is older than the idle retention limit. A stale multi-tick transcript regression and resident totals compared with otak-usage verified the failure and fix.
- Codex dedupe keys must preserve RFC3339 milliseconds; rounding timestamps to seconds can merge distinct same-second events with equal token counts.
- Measure production catch-up as work batches times timer interval before shipping a checkpoint schema rebuild. A 10,300-tick scan at 60 seconds per tick takes days even when the collector itself finishes in about 100 seconds; bound catch-up cadence and coalesce durable writes while keeping network fetch and hot-file restat cooldowns independent.
- Claude JSONL can repeat the same message/request identity with increasing cumulative output usage: a record with `stop_reason: null` can be followed by a final `tool_use` or `end_turn` record. The 2026-09-22 resident audit reproduced 24 final updates discarded by boolean dedupe. Usage accounting must distinguish replay from a usage revision and preserve that distinction across restart; matching the existing first-record calculation does not establish correct billing usage.
- Audit resident usage against an immutable generation and its per-file offsets. Archived Codex logs can explain a Today replay gap, while deleted logs make the complete Month total unreconstructable; a smaller sum of remaining files is not proof of overcount. Preserve the production checkpoint during investigation.
- Recheck provisional pricing against current provider documentation. On 2026-09-22 Anthropic documented cancellation of the Sonnet 5 September increase ($2/$10 remains standard), and OpenAI documented Daybreak Blue as a Sol alias plus a separate 1.25x cache-write rate. Real resident source logs contained this alias and nonzero `cache_write_input_tokens`; neither was priced by v1.1.34.
- Compare resident usage against otak-usage's displayed persistent cache, not a fresh scan of surviving JSONL files. Deleted current-month Codex files remain in its day buckets. Keep the extension total as an independent display floor over the local JSONL aggregate: applying it additively risks double counting, while waiting for all restored registrations and a snapshot newer than every live write can starve the Month display for hours.
- In current-month JSONL collector tests, generate event timestamps inside the collector's local day with `stamp_at(stable_test_now())`. A month-end `23:00Z` fixture landed in the following month in JST and made a two-file ordering test count only one file; the stable local-day fixture restored the full library suite.
- New model IDs can inherit an older model's dated price revision through prefix matching. Add an explicit pricing entry and verify the effective-day rate against current provider documentation; Claude Sonnet 5.5 incorrectly inherited the cancelled September 2026 Sonnet 5 increase until both the entry and stale revision were corrected.
- GitHub Web rebase-and-merge can replace a project-authored commit's committer with the personal account name and email. After PR CI, audit the actual main history before tagging a public release. For #97, a lease-checked rewrite to the original project-authored commits removed the two personal committer records; restore required checks and force-push protection immediately, then rerun Verify on the final main SHA.
- A fixed-prefix search of pending usage files can starve today's file when the backlog exceeds that prefix, and pending reads can consume the entire tick before a live append is restatted. Search the pending queue in O(N) and reserve one bounded hot-file read while keeping a separate pending budget; component regressions with 65 older files and a saturating old read verified both Today and backlog progress.
- Parenthesize compound right-hand sides in TLA+ next-state assignments. `pendingToday' = pendingToday /\ ~QueuedRead` was parsed as an action guard and left initial states deadlocked; `pendingToday' = (pendingToday /\ ~QueuedRead)` produced the intended transitions. Check TLC's reachable-state count and run fault configurations to avoid a vacuous PASS.
- Compare both Claude and Codex Today with otak-usage's fenced day snapshot. On 2026-10-07 the resident local Claude checkpoint showed about $4.88 while the extension snapshot showed $119.63; a fresh scan of surviving files produced a monthly total close to the extension's. Apply each provider's cache as an independent display floor, never add it to or persist it in the local aggregate, and cover both providers plus unavailable-provider cases in tests.
